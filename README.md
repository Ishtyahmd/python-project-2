# DATA ANALYSIS PROJECT REPORT: Temporal Patterns in Urban Crime 

---

## 1. Executive Summary 
This project investigates urban crime patterns using a dataset of over 1,000 incidents . The primary goal was to identify how time-based variables—such as the hour of the day and the day of the week—influence crime frequency and type. Using **Pandas** for data manipulation and **NumPy** for statistical anomaly detection, the analysis revealed that crime is not evenly distributed across the clock.
